### ✅ Global Page Cleanup

```js
window.cleanupPage()
```

One of the most important systems.

Before switching page:

- old listeners removed
- old intervals cleared
- old observers destroyed
- old runtime cleaned

This prevents:

- memory leaks
- duplicated events
- FPS drops
- RAM increase
